# BanglaScript for Vim / Neovim

## Installation

### For Vim:
Copy the syntax and ftdetect files into your `~/.vim` directory:
```bash
mkdir -p ~/.vim/syntax ~/.vim/ftdetect
cp editors/vim/syntax/banglascript.vim ~/.vim/syntax/
cp editors/vim/ftdetect/banglascript.vim ~/.vim/ftdetect/
```

### For Neovim:
```bash
mkdir -p ~/.config/nvim/syntax ~/.config/nvim/ftdetect
cp editors/vim/syntax/banglascript.vim ~/.config/nvim/syntax/
cp editors/vim/ftdetect/banglascript.vim ~/.config/nvim/ftdetect/
```
