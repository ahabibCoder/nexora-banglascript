# BanglaScript for JetBrains IDEs (CLion, IntelliJ IDEA, PyCharm, WebStorm)

JetBrains IDEs natively support TextMate bundles for custom language syntax highlighting.

## How to Enable:

1. Open your JetBrains IDE settings (`File -> Settings` on Windows/Linux or `Preferences` on macOS).
2. Navigate to **Editor -> TextMate Bundles**.
3. Click the `+` icon to add a new bundle.
4. Select the directory:
   `editors/vscode-banglascript`
5. Click **Apply** and **OK**.
6. Open any `.bs` file — syntax highlighting for Latin and Bengali keywords is now active!
