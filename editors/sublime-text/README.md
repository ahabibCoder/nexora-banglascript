# BanglaScript for Sublime Text

## Installation

1. In Sublime Text, open the Packages folder:
   - On Windows: `%APPDATA%\Sublime Text\Packages`
   - On macOS: `~/Library/Application Support/Sublime Text/Packages`
   - On Linux: `~/.config/sublime-text/Packages`
2. Create a folder named `BanglaScript`.
3. Copy `BanglaScript.sublime-syntax` into that folder.
4. Any `.bs` file will now feature full syntax highlighting for both Latin and Bengali Unicode keywords!
