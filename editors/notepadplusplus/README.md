# BanglaScript for Notepad++

## Installation

1. Open Notepad++.
2. Click **Language -> User Defined Language -> Define your language...**
3. Click **Import...** and select `editors/notepadplusplus/banglascript.xml`.
4. Restart Notepad++ or open any `.bs` file.
5. In the **Language** menu, select **BanglaScript**.
